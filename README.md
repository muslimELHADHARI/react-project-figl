# MoslemStore

Landing page de boutique en ligne réalisée avec **React.js**, **React-Bootstrap** et **CSS**, avec Vite.

## Démarrer

```bash
npm install
npm run dev
```

## Compiler

```bash
npm run build
npm run preview
```

## Fonctionnalités

- Navbar responsive et menu mobile.
- Carrousel React-Bootstrap de 3 slides avec images, titres, navigation et indicateurs.
- 4 produits dans des composants Card React-Bootstrap.
- Filtrage par catégorie et boutons Add to Cart.
- Panier en panneau latéral : ajout, suppression, quantités et total.
- Notifications d’ajout et état vide du panier.
- Footer avec copyright, navigation par ancres, adaptation mobile et respect du réglage de réduction des animations.

Le panier reste en mémoire pendant la session de la page. Il s’agit d’une démonstration sans backend, paiement ni commande réelle. Les photographies proviennent d’Unsplash ; les polices Google Fonts et les photos nécessitent une connexion Internet. Les noms, prix et engagements sont des contenus de démonstration.

La référence visuelle n’était pas jointe à la demande : une direction originale, orientée mobilier et décoration, a été créée.
